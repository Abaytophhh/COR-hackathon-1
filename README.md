# AI Trust — обновлённый интерфейс

Этот проект основан на `ai-trust-mvp`. Главная страница использует дизайн и локализацию RU/KK из архива дизайнера. Проверка нового ответа идёт через серверную функцию исходного проекта (`src/lib/factcheck.functions.ts` → `src/lib/factcheck.server.ts`). Другие маршруты и серверная архитектура базы сохранены.

## Запуск

Нужны Node.js и npm, совместимые с Vite 8.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для проверки сборки выполните `npm run build`.

Если у вас есть разрешённый ключ Lovable AI Gateway, задайте переменную `LOVABLE_API_KEY` **на сервере** перед запуском. В браузер ключ не передаётся. При отсутствии ключа или ошибке запроса исходный движок базы возвращает запасной результат `MISLEADING`; это техническая заглушка, а не подтверждённый фактчек. Перед демонстрацией реальной проверки настройте шлюз и проверьте качество результатов на конкретных примерах.

## Что перенесено

- Интерфейс, CSS, демо-данные и локализация дизайнера находятся в `src/design/`.
- `/` показывает новую главную страницу, ленту, карточки, детали, комментарии, RU/KK и отправку ответа.
- Отправка вызывает существующий серверный `checkFact`. Результат сохраняется локально и отображается как автоматический общий вердикт. Движок базы не возвращает проверку каждого отдельного утверждения и документальные URL; интерфейс не обещает этого для новых отправок.
- Существующие `/live-check`, `/business` и `/case/:id` остаются доступными с прежним интерфейсом.
- Метаданные, шрифты и иконка из `index.html` дизайнера перенесены в `<head>` маршрута TanStack Start (`src/routes/__root.tsx` и `src/routes/index.tsx`). Исходный HTML сохранён только для сравнения в `design-reference/index.html`: корневой `index.html` не является точкой входа TanStack Start.
- Обновлённый README заменяет базовый шаблон Lovable и описание отдельного Vite SPA.

## Зависимости

Новых **названий** пакетов по сравнению с базовым `package.json` нет. У дизайнера `@tailwindcss/vite` и `tailwindcss` записаны в `devDependencies`, но в базе они уже есть в `dependencies`. Версии общих пакетов различаются:

| Пакет | База | Дизайнер |
| --- | --- | --- |
| `lucide-react` | `^0.575.0` | `^1.48.0` |
| `react`, `react-dom` | `^19.2.0` | `^19.3.0` |
| `@tailwindcss/vite`, `tailwindcss` | `^4.2.1` | `^4.3.3` |
| `@vitejs/plugin-react` | `^5.2.0` | `^6.1.1` |
| `vite` | `8.1.5` | `^8.3.1` |

`package.json` базы оставлен без изменений. Не заменяйте его, `vite.config.ts` или `bun.lock` файлами из SPA: у дизайнера другая система запуска и нет серверного модуля проверки.

## Данные и ограничения

Демо-карточки взяты у дизайнера, комментарии, баллы и новые проверки хранятся в браузерном `localStorage`. Ссылки `#/q/<id>` открывают детали на главной странице. Смена браузера или сброс локальных данных удалит созданные пользователем записи. Демо-карточки с разбором утверждений подготовлены заранее; новый запрос получает общий вердикт, объяснение и предложенные домены, а не документы с доказательствами или рецензию живого эксперта.
